# starcoop

Automated bidding agent for **SECOP II** electronic reverse auctions
(*subastas inversas electrónicas*), built for **Cooperativa de Vigilantes STARCOOP CTA.**

> **Start here → [`SOT.md`](SOT.md)** — the Source of Truth. It is the authoritative
> record of decisions, known facts, and open questions.

---

## The problem

Colombian public contracts are frequently awarded by reverse auction: qualified bidders
undercut each other inside a ten-minute window and the lowest compliant price wins.
Winning depends on reacting within seconds, holding a live connection, and knowing
exactly when to stop. A human doing this in a browser is slow, gets disconnected, and
cannot compute the profitable stopping point under pressure.

This project automates STARCOOP's **own** bids on STARCOOP's **own** account.

## What makes it hard

| Constraint | Consequence |
|---|---|
| Lower price wins | A bug that bids too low *wins at a loss* and binds the cooperative to deliver |
| A bid in the final minute extends the auction by 3 minutes | Last-second sniping does not work; disciplined persistence does |
| The connection drops mid-auction (observed) | Reconnection is a core feature, not error handling |
| Login is reCAPTCHA-gated | Sessions bootstrap through a real browser, assisted by a human |
| The whole event lasts 10 minutes | Every decision is on a hard deadline |

## The one rule

**A human sets the floor price. The bot only obeys it.**

The floor is enforced in multiple independent layers so that no single failure can
produce a bid below cost. The bot does not decide what a contract is worth — it decides
how to compete down to a limit someone else already approved.

## Regenerating the API contract

The contract chapter is generated, not hand-written. Given a directory of HAR captures:

```bash
python3 tools/digest_har.py         /path/to/har-directory docs/01-api-contract.md
python3 tools/extract_vocabulary.py /path/to/har-directory docs/09-platform-vocabulary.md
```

The tool redacts JWTs and sensitive headers so its output is safe to commit. Verify
before committing anyway:

```bash
grep -c 'eyJ' docs/01-api-contract.md   # expect 0
```

## 🔒 Security

Raw captures contain **live session credentials**. `.gitignore` blocks `*.har`,
`TOKEN*.txt`, `*.mp4`, `*.rar`, `*.zip`, `.env` and browser storage state. Never
override it.

The evidence bundle this project was built from leaked a live JWT and session cookies.
**The SECOP II account password must be rotated before the bot goes live.** See
[`SOT.md`](SOT.md) §3.

## ⚖️ Scope and legality

This tool automates one company's own bids on its own account — the electronic
equivalent of that company's own employee clicking faster. It does **not** coordinate
with other bidders. Bid rigging (*colusión en licitaciones*) is a crime in Colombia under
Ley 1474 de 2011 art. 27 and Código Penal art. 410A, and nothing in this repository may
be used to facilitate it.

Read [`docs/05-compliance.md`](docs/05-compliance.md) before running anything against the
live platform.
